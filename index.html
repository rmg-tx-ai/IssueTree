Structured Problem-Solving
Break any problem into a clear, testable tree of issues.
Issue trees are a cornerstone of top-tier analytical work. Start with a single root question, then decompose it into mutually exclusive, collectively exhaustive (MECE) branches — each one a testable hypothesis. Prioritize the branches most likely to drive the answer, go deep only where it matters, and let the structure reveal where evidence is missing and where it's not.
❶
Frame the root question
State the core problem as a single, specific question — not a topic. A sharp root node keeps every branch on-mission.
❷
Decompose MECE
Each level should be mutually exclusive and collectively exhaustive. No overlaps, no gaps. Use the ⋮ menu to add, rename, and reorder children.
❸
Prioritize & test
Mark high-impact branches as Priority. Focus subtrees to work deep without losing context. Hypotheses should be falsifiable — update the tree as evidence comes in.
